About Podfessor

Podfessor turns course material into short, podcast-style lessons. Pick a course, ask a question about it, and Podfessor writes a friendly script that explains the topic the way a professor would on a podcast.

Create an account to add your own courses, topics and notes. When you ask about one of your courses, Podfessor uses your notes to tailor the lesson.

The front end is plain HTML, CSS and JavaScript. It talks to a REST API written in PHP, which stores courses and accounts in a MySQL database and calls the OpenAI API on the server, so the API key is never exposed in the browser.
