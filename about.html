About Podfessor

Podfessor turns course material into short, podcast-style lessons. Pick a course, ask a question about it, and Podfessor writes a friendly script that explains the topic the way a professor would on a podcast.

The front end is plain HTML, CSS and JavaScript. Questions are sent to a small PHP endpoint, which calls the OpenAI API on the server so the API key is never exposed in the browser.

Coming next: saved courses and notes in a SQL database, user accounts, and text-to-speech audio for each lesson.
